# ⚡ PX Bot v1.2.0 (Flat Version)

ربات فروش کانفیگ حرفه‌ای + پنل وب مینیمال  
**همه چیز در یک فایل `main.py` — بدون هیچ فولدری**

---

## ساختار فایل‌ها (همه در root)

```
main.py              ← کل کد ربات + وب + دیتابیس + پنل‌ها
requirements.txt
Procfile
railway.toml
.env.example
.gitignore
README.md
```

هیچ پوشه‌ای وجود ندارد. فقط این چند فایل را در root ریپوی GitHub بگذارید.

---

## دیپلوی روی Railway

1. ریپو بسازید و فقط همین فایل‌ها را پوش کنید.
2. New Project → Deploy from GitHub
3. بعد از بالا آمدن به آدرس وب بروید → `/setup`
4. توکن ربات + آیدی عددی ادمین‌ها (هر خط یک آیدی) را وارد کنید.

**رمز پنل وب:** `pxadmin`
