# PX Bot v2.3.0 (NEW BOT)
## ربات فروش کانفیگ px به صورت رایگان بر روی ریلوی 

## قابلیت‌های بات
- کیف پول کاربران
- انبار محصولات
- افزودن محصول از ربات و سایت
- تصویر کارت بانکی هنگام خرید
- مسدودسازی کاربران
- بک‌آپ و بازیابی از ربات و سایت
- ویرایش قوانین از ربات
- مدیریت کامل پنل‌ها، پرداخت، عضویت اجباری
- اتصال پاسارگارد / مرزبان / سنایی
- پنل وب برای مدیریت کامل
