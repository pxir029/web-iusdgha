# ⚡ PX Bot v2.1.0 (Flat)

ربات حرفه‌ای فروش کانفیگ — همه چیز در یک فایل

## قابلیت‌ها
- دکمه‌های رنگی و هم‌اندازه
- کیف پول کاربران
- انبار محصولات (stock)
- افزودن محصول از ربات و سایت
- تصویر حرفه‌ای کارت بانکی هنگام خرید
- مسدودسازی کاربران
- بک‌آپ و بازیابی از ربات و سایت
- ویرایش قوانین از ربات
- مدیریت کامل پنل‌ها، پرداخت، عضویت اجباری
- اتصال پاسارگارد / مرزبان / سنایی
- پنل وب گلس‌مورفیسم بدون سایه

## فایل‌ها (همه در root)
main.py · requirements.txt · Procfile · railway.toml · .env.example · README.md

## دیپلوی
بعد از Deploy به /setup بروید و توکن + آیدی ادمین را وارد کنید.
